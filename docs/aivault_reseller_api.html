GUARANTEES

Atomic Settlement & Zero-Debit Idempotency

Automated reseller integrations require absolute financial reliability. Our platform is built on two core guarantees:

🛡️
1. Single-Commit Atomic Settlement

Wallet deductions and order creation execute inside a single atomic SQLite transaction (BEGIN IMMEDIATE ... COMMIT). If fulfillment fails, funds automatically roll back. You are never debited without an order.

🔄
2. Idempotent Replays (external_order_id)

Pass your internal order reference in external_order_id when placing orders. If a network connection drops and your bot retries, the API returns the original order with "idempotent_replay": true — zero duplicate debits or duplicate orders.

REAL-TIME WEBHOOKS

Webhooks Architecture & Cryptographic Verification

Webhooks eliminate the need for your bot to constantly poll the server asking "Is the order ready yet?". Whenever an order is delivered or queued, our engine immediately pushes a signed HTTPS POST notification directly to your server.

🔔
order.delivered

Fired when digital keys / coupons are assigned and ready for your customer.

⏳
order.queued

Fired when stock is pending restock. Your order will fulfill automatically once restocked.

⚠️
order.failed

Fired if delivery encounters an unrecoverable exception or error.

HMAC-SHA256 Signature Verification

Every webhook delivery includes header X-Webhook-Signature: sha256=<hex>. Use your webhook secret to cryptographically verify authenticity:

Python Signature Verifier 
import hmac, hashlib

def verify_webhook(raw_payload_bytes, signature_header, webhook_secret):
    expected = "sha256=" + hmac.new(webhook_secret.encode(), raw_payload_bytes, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature_header)

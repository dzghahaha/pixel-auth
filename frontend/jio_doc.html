📖 业务规则与兑换指南

兑换链接使用三步法：
① 手机或者电脑登录好你要领取的账号
② 将收到的兑换链接粘贴到您的谷歌浏览器中打开
③ 然后单击“蓝色按钮”激活优惠。您的将成功激活。
⏳ 提示：兑换链接有效期为 6~12 小时，通过 API 获取后请指示用户及时在谷歌浏览器中打开并激活！

1. Jio 卡密核销兑换接口

调用该接口核销 Jio 专属卡密，系统立即返回对应的 Google One 优惠兑换链接。接口具备防并发重放机制与历史订单幂等保护。

接口地址： /api/jio/redeem
请求方式： POST
Content-Type： application/json

请求参数 (Request Body)

参数名 类型 必填 说明
card_secret string 是 购买的有效 Jio 专属卡密字符串

请求示例 (cURL)

curl -X POST "https://YOUR_DOMAIN/api/jio/redeem" \ -H "Content-Type: application/json" \ -d '{ "card_secret": "JIO-9876-ABCD-1234" }'

成功响应 (Response 200)

{ "success": true, "message": "获取成功", "data": { "card_secret": "JIO-9876-ABCD-1234", "offer_url": "https://one.google.com/promo/hasoffer?token=JIO_OFFER_SAMPLE_TOKEN", "created_at": "2026-09-14 15:30:00" } }

维护挂起响应 (系统维护开启时)

{ "success": true, "message": "Jio系统维护中，订单已暂存挂起，维护结束后将恢复处理并生成链接", "data": { "card_secret": "JIO-9876-ABCD-1234", "status": "paused", "offer_url": "", "message": "Jio系统维护中，订单已暂存挂起，维护结束后将恢复处理并生成链接" } }

失败响应 (Response 400 / 500)

{ "success": false, "message": "此卡密非 Jio 专用卡密，请前往对应页面使用" }

2. Jio 订单状态与历史链接查询

通过卡密查询该卡密的历史核销记录及已生成的兑换链接，若链接未失效可重复取回。

接口地址： /api/query
请求方式： GET

请求参数 (Query Parameters)

参数名 类型 必填 说明
card_secret string 是 已兑换的 Jio 卡密

成功响应 (Response 200)

{ "success": true, "service_type": "jio", "card_secret": "JIO-9876-ABCD-1234", "created_at": "2026-09-14 15:30:00", "records": [ { "id": 108, "status": "success", "message": "兑换链接获取成功", "discount_url": "https://one.google.com/promo/hasoffer?token=...", "completed_at": "2026-09-14 15:30:01" } ] }
